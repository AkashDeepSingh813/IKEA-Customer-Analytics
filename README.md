# IKEA Customer Analytics & RFM Segmentation

**Tools:** SQL | Python | Power BI 

## 📌 Project Overview

Analyzed 1.06M+ retail transaction records to identify valuable customer segments, understand purchasing behavior, and assess churn risk using SQL, Python, and Power BI.

## 🔄 Methodology

- **SQL:** Cleaned, deduplicated, and prepared transaction data.
- **Python:** Implemented RFM analysis to classify customers into six segments and identify churn using a 90-day inactivity threshold.
- **Power BI:** Developed a three-page interactive dashboard to analyze customer value, revenue contribution, segment performance, and churn trends.

## 💡 Key Insights

- Identified a **50.9% churn rate**.
- The Champions segment generated approximately **$11.84M in revenue**.
- Identified opportunities for targeted customer retention and re-engagement strategies.
